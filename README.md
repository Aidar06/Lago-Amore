# Lago Amore

Адаптивный свадебный сайт-приглашение с данными из Xano.

## Возможности

- загрузка приглашения по адресу `/{public_id}`;
- языки RU, KG и KZ в соответствии с `languages.enabled` из API;
- имена, дата, тексты, программа, место, пожелания и настройки RSVP берутся из Xano;
- ответы гостей отправляются через `POST /priglosi/{public_id}/rsvp`;
- облегчённый статичный режим `/preview` показывает первый экран без запроса к API;
- адаптивная мобильная вёрстка и живой обратный отсчёт.

## Локальный запуск

```powershell
npm run dev
```

Откройте:

- `http://127.0.0.1:4202/12` — приглашение с тестовым `public_id`;
- `http://127.0.0.1:4202/preview` — облегчённое превью.

## Проверка перед публикацией

```powershell
npm run check
```

Проект статический. Для Vercel уже настроена публикация папки `dist` и перенаправление всех маршрутов на `index.html`.
